# Hardware image placeholders

Each SVG is a local stand-in for one hardware card. Replace the matching file with a real prototype image and update that card's `image` path in `src/App.tsx` if the replacement uses a different file extension.

- `optical-drop-sensor-placeholder.svg`
- `stm32-controller-placeholder.svg`
- `servo-pinch-mechanism-placeholder.svg`
- `esp-01-wireless-module-placeholder.svg`

The cards use a fixed 16:10 display ratio, so landscape photos work best.
